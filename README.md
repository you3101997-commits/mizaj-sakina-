# مِزاج وسكينة — مشروع Android

هذا مجلد مشروع Android كامل لتحويل نسخة HTML المرفقة إلى تطبيق Android باستخدام WebView، مع أيقونة التطبيق المرفقة وربط إعداد الإشعارات بأندرويد.

## محتويات المشروع

- `app/src/main/assets/index.html`: نسخة التطبيق HTML المضمنة داخل التطبيق.
- `app/src/main/java/com/mizaj/sakina/`: كود Kotlin لواجهة التطبيق وربط JavaScript والإشعارات المجدولة.
- `app/src/main/AndroidManifest.xml`: تعريف التطبيق وأذونات الإشعارات.
- `app/src/main/res/`: أيقونات التطبيق، بما فيها الصورة الأصلية التي أرسلها المستخدم ونسخ الأيقونة بمقاسات Android.
- `.github/workflows/build-apk.yml`: بناء APK تلقائيًا عبر GitHub Actions.

## رفع المشروع إلى GitHub من الهاتف

1. نزّل ملف ZIP وفك ضغطه.
2. افتح مستودع GitHub الذي تريد استخدامه.
3. ارفع **كل محتويات مجلد `mizaj-sakina-android`** إلى جذر المستودع، وليس مجلدًا إضافيًا بداخله.
4. تأكد من ظهور المجلد المخفي `.github/workflows` والملف `build-apk.yml`. إذا لم يظهر `.github` عند الرفع من الهاتف، أنشئ المجلدات يدويًا وارفع الملف.
5. بعد رفع الملفات افتح تبويب **Actions** وشغّل **Build Mizaj Sakina Android APK** إذا لم يبدأ تلقائيًا.
6. عند نجاح المهمة، افتحها ثم نزّل Artifact باسم `Mizaj-Sakina-Android-APK`.

## الإشعارات

يحتوي المشروع على قناة إشعارات Android وجدولة محلية عبر WorkManager. من داخل التطبيق افتح إعدادات الإشعارات، فعّل الإشعار، اختر الوقت، واسمح بإذن الإشعارات عندما يطلبه Android.

قد يؤخر Android وقت وصول الإشعار قليلًا بسبب تحسين البطارية أو قيود الشركة المصنّعة. يجب تجربة APK المثبت فعليًا للتأكد من عمل الإشعارات على الهاتف.

## ملاحظة البناء

GitHub Actions يبني نسخة Debug APK للتجربة. نجاح رفع الملفات لا يعني أن APK بُني بالفعل؛ يجب انتظار نجاح مهمة Actions وتنزيل ملف Artifact.
